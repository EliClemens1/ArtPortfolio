# ArtPortfolio

A modern portfolio web application for showcasing artwork collections online.

## Features

- Browse artwork in a clean, responsive gallery
- View detailed information about each piece
- Multiple images per artwork
- Categorize artwork by medium, style, and subject
- Firebase Authentication for secure administration
- Upload and manage artwork through an admin interface
- Store images using Firebase Storage
- Export artwork data to JSON or CSV
- Mobile-friendly design

## Built With

- Vue 3
- Vite
- Firebase Authentication
- Firestore Database
- Firebase Storage
- HTML5
- CSS3
- JavaScript
